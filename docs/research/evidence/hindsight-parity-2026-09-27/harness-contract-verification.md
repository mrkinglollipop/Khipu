## Caveats

The source claims prior acceptance, but no installed runtime was inspected. In particular, config detection is not hook execution; gateway `/healthz` build identification is not a cloud-agent recall/capture proof; and a 600-character injected block loses any newly added result fields unless its renderer contract changes. `khipu_search` treats legacy `semantic=true` (when `mode` is omitted) as **semantic**, not hybrid (`mcp_server.py:475-496`); an external semantic-default consumer therefore needs an explicit adapter/opt-in to receive enhanced hybrid ranking. `khipu_status(prompt)` does map to the bounded `prior_work_for_prompt(..., budget_ms=...)` path, default 600 ms and clamp 100–5000 ms (`mcp_server.py:674-677,773-814`; `recall_prompt.py:417-570,624-690`).
