## Changes

- `packages/cli/khipu/routing_identity.py:19`: stable provider/label ids,
  duplicate slug rejection, permanent historical bindings and ordered owner
  rename forwards. Crossing renames also forward the losing destination.
- `packages/cli/khipu/routing.py:5814`: append-only, idempotent migration;
  salted aliases are recorded only when this installation has an id salt.
  The first migration witness owns their 90-day start across restores.
  Config stores this Mac's `routing_account_bindings`; login folders stay local.
- `packages/cli/khipu/routing.py:5839`: stable resolution and explicit dated
  expiry errors naming the replacement id. Report and MCP filter paths use
  the same alias checks. Expiry never removes the historical fold mapping.
- `packages/cli/khipu/routing.py:2410`: stable ids, migration aliases and old
  login keys fold through the current local binding. Existing folder-move
  eras are resolved first, preserving their ownership semantics.
- `packages/cli/khipu/accounts.py:418`: existing account transactions update
  local bindings and write owner rename events. Conversations cannot rename
  accounts. Earlier forwarded ids cannot be reused for another login.
- `packages/cli/khipu/usage.py:1701`: account-list writes reject labels that
  collapse to the same provider slug, including unchanged stored duplicates.
- `packages/cli/tests/test_routing_acceptance.py:785`: remove all four slice
  3a decorators (six parameterized cases). The alias setup now explicitly
  creates a legacy salted id, rather than asking the new stable-id function
  to produce one. Its live/expiry/restore assertions are retained.
- `packages/cli/tests/test_routing_acceptance.py:835`: fix the 11a golden to
  compare effective state without account presentation labels or attribution
  wording. A separate migration replay compares the complete before/after
  effective views and verifies that the old log bytes remain an unchanged
  prefix, with only one migration appended.
- `packages/cli/tests/test_routing_acceptance.py:861`: ten additional cases
  cover migration idempotence, local bindings, no aliases on fresh installs,
  exact expiry, owner rename/history, conversation refusals, crossing renames,
  forwarded-label reuse, restored history under a different local binding,
  and duplicate slugs.
- `packages/cli/tests/test_routing_mcp.py:493` and
  `packages/cli/tests/test_routing_priority.py:315`: replace retired `acct-`
  output expectations with exact stable ids. All path/privacy assertions
  remain; the legacy-alias test still checks keyed hashing and salt mode 0600.
