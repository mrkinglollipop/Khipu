## Sanitizer and isolation

- `scripts/routing_fixture_sanitize.py` reads explicitly supplied stdin only. It performs no log discovery, network call, credential read, or model call. Unknown keys fail closed, including nested author, scope and priority entries.
- Routing replay fixtures use `routing_replay_v1`: relational synthetic aliases, integer times relative to an origin, and equal-length `x` text. Replay decodes that closed format into real routing event shapes under a temporary HOME.
- `pace_fixture_v1` permits exactly `acct`, `win`, `t`, `t_err`, `used`, `reset`. Account/window ids are synthetic aliases; times are integer seconds; nonfinite values, booleans, invalid ranges, extra keys and arbitrary strings are refused.
- The fixture inventory includes slice 1's `routing_delivery_oct14_19.jsonl`, the sanitized replay, and the synthetic pace history. Slice 1's legacy format is checked against an exact synthetic vocabulary as well as the sanitizer. Adding an unreviewed replay fixture fails the inventory check.
- Negative tests cover Unix and Windows paths, a bare home-folder name, a UUID-like session id and free conversation text in every routing string boundary; pace schema extensions and malformed numeric fields; deterministic aliases, preserved relationships, text lengths and clock intervals; and sentinel-free stdout, stderr and rejection messages.
- All fixtures were made from synthetic repository data or numeric vectors. No private log, `~/.config/khipu`, live state, or live hub was accessed.
- The rig uses isolated HOME/data/capture directories, a controlled clock, real in-process fold/marker/hook/MCP paths, and an in-memory ordered test hub. It prevents network connections and subprocess launches. Attempted forbidden calls remain recorded even if production catches their exception, so teardown fails rather than hiding an attempted escape.
- The closed gateway-field checker is tested at every listed object depth and against nested history and path leakage. This validates the checker, not a deployed gateway.
