Each row is one bounded session with its own brief, owned files and oracle. The oracle for every Khipu session is the hermetic suite from Phase 0, run from `packages/cli`; the gate is no failure outside the 11 named baseline failures. Root owns integration and final checks; each repeated oracle has at most three attempts per change, including root's reserved final run. A session that needs a mock, a decision or an access it does not have stops and reports.
