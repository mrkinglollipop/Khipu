Khipu only reads these folders. It never writes to them, never changes a runner's settings, and reads only its limits, its job starts, its heartbeat and the few lane settings it needs to watch your rules. Every line it keeps is checked for secrets first. A folder inside API Keys, My Portfolio or any sign-in file is refused.
