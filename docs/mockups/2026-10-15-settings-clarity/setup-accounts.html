Welcome to Khipu

Install: open the disk image and drag Khipu.app into the Applications folder, then launch it from Applications (not from the disk image).

Khipu gives your coding agents a memory that outlives the session. Each agent records what happened, the database keeps it as searchable text and a map of what connects to what, and the next session reads it back, from any of your Macs.

Setup is seven steps. Each one checks itself, so you can close this and come back; nothing here has to be finished in one go.

  • Database: join a Khipu you already have, set one up on this Mac, or connect to one you run.
  • Model: cloud Gemini, a local model, or skip for now (recording waits, nothing is lost).
  • Graph: installs the graph builder next to the app.
  • Agents: one click per harness to wire in recording.
  • Accounts: see how much of each plan is left and tell your agents which accounts have room. Optional.
  • Finish: a health check, and where to get help.
